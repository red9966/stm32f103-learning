# 环境搭建与下载方式（STM32F103）

## 一、两条可选路线

| 路线 | 工具 | 说明 |
|---|---|---|
| **A. 标准库 + Keil（江协主线）** | Keil MDK5 + DFP + 课程模板 | 跟着 2023 版课程走，最省心 |
| B. HAL + CubeMX | STM32CubeIDE（或 CubeMX + Keil） | 用江协 HAL 库重制版课程；工具链更现代 |

**建议**：先走 A 跟完主线（课程讲得细、配套资料全），实验 12 完成后再用 B 重做一遍——这一步能让你同时具备"标准库 + HAL"两种经历，面试时是个加分项。

## 二、路线 A：Keil 环境搭建

1. 安装 **Keil MDK5**（注意路径不要含中文；MDK 对中文/全角字符路径很敏感）
2. 用 Pack Installer 安装 **``Keil.STM32F1xx_DFP``**（STM32F1 器件支持包）
3. 打开江协课程配套的**工程模板**（资料包里提供），确认能编译
4. 编译产物在 ``Objects/``、``Listings/`` —— 已在 ``.gitignore`` 中排除

## 三、下载程序（两种方式）

### 方式 1：串口下载（成本最低，只需 USB-TTL）

1. 接线：CP2102 的 TX → 板子 PA10(RX)，RX → 板子 PA9(TX)，**GND 必须共地**，3.3V 逻辑
2. 板子跳线：**BOOT0 = 1，BOOT1 = 0**，按复位进入系统存储器启动
3. 用 **FlyMcu** 或 STM32CubeProgrammer（UART 模式）选择编译出的 ``.hex`` 下载
4. 下载完成后 **BOOT0 跳回 0**，按复位运行
5. 也可以用这个串口看 printf 输出（PA9/PA10 同时是 USART1）

### 方式 2：ST-Link（推荐，能调试）

1. 接线：SWDIO / SWCLK / GND / 3.3V 四根
2. Keil 中 ``Options for Target → Debug`` 选 **ST-Link Debugger**，Settings 里能识别到芯片 ID
3. 可以直接 **Download（F8）**，也能打断点单步调试 —— **调试能力是你后面排障的本钱，建议尽早用起来**

## 四、⚠️ 路径与常见坑

| 坑 | 说明 |
|---|---|
| **中文 / 全角括号路径** | 你的用户目录是 ``C:\Users\Admin（无密码）\``，含中文和全角括号。**工程统一放在本项目目录** ``E:\stm32\stm32f103-learning`` 下 |
| 下载后不运行 | BOOT0 忘记跳回 0 |
| 串口乱码 | 波特率不一致 / TX-RX 没交叉 / 没共地 |
| 串口无输出 | USART 选错（F103 常用 USART1 = PA9/PA10）、引脚被复用 |
| 5V 接 3.3V IO | CP2102 与模块务必确认 3.3V 逻辑电平 |
| Keil 编译报错找不到头文件 | 工程模板路径变了 / 中文字符路径 |
