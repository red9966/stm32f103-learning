# 硬件与接线总说明（STM32F103C8T6）

## 一、主控芯片

| 参数 | 值 |
|---|---|
| 型号 | STM32F103C8T6 |
| 内核 | ARM Cortex-M3 |
| 主频 | 最高 72 MHz |
| Flash / SRAM | 64 KB / 20 KB |
| 封装 | LQFP48 |

## 二、板载与套件

- 江协科技 STM32 入门套件：F103C8T6 开发板 + 830 孔面包板 + 杜邦线 + 常用模块（OLED、传感器、按键、LED 等）
- 板载 HSE 晶振通常为 **8 MHz**（以课程资料与板子丝印为准）
- **套件本身没有 CAN 收发器**，第 8 周需另配 SN65HVD230

## 三、常用引脚速查（以课程资料与数据手册为准）

| 功能 | 引脚 | 说明 |
|---|---|---|
| USART1 | PA9 (TX) / PA10 (RX) | 最常用；串口下载与 printf 输出 |
| USART2 | PA2 (TX) / PA3 (RX) | 第二路串口 |
| I²C1 | PB6 (SCL) / PB7 (SDA) | |
| SPI1 | PA5 (SCK) / PA6 (MISO) / PA7 (MOSI) | |
| CAN | **PA11 (CAN_RX) / PA12 (CAN_TX)** | 默认；可重映射到 PB8/PB9 |
| 板载 LED | PC13 | 多数 F103 最小系统板 |

## 四、CAN 接线（第 8 周）

```text
STM32 PA12 (CAN_TX) ──► SN65HVD230 TXD
STM32 PA11 (CAN_RX) ◄── SN65HVD230 RXD
                        CANH ──┬── CANH(另一节点)
                               └── 120Ω ── CANL
                        CANL ──┘
```

- **两端各一个 120 Ω 终端电阻**
- 两个节点 **必须共地**
- 收发器用 **3.3V（SN65HVD230）**，不要用 5V 型号
- 第二个节点：江协套件里若只有一块板，可用 G431 或另一块 F103

## 五、安全与顺序

1. 接线前**断电**
2. 上电顺序：先接 GND，再接信号
3. 排查顺序：**电源 → 3.3V → GND → 信号 → 最后才查软件**
