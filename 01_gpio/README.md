# 01\_gpio

## 目的：

&#x09;按键控制LED的亮灭

## 接线

|MCU 引脚|连接对象|说明|
|-|-|-|
|PA0,PA3，PB0,PB11|两颗LED,两个按键||

## 关键配置

1.对LED的GPIO接口进行初始化，设GPIOA与B均在APB2总线上，先进行端口使能配置，随后建立结构体函数将端口输出初始化。

2.对按键的GPIO接口进行初始化，与LED接口配置相似，模式改为上拉输出。

3.可通过建立端口初始化的封装函数来简化主程序的变成步骤。
