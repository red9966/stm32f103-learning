# stm32-g431-learning

12 周 STM32 裸机学习实验（主线课程：江协科技《STM32入门教程-2023版》）。
目标：第 12 周结束时做到「我不看教程，给我一块 G431，我能从零建立工程」。

## 硬件
- ST NUCLEO-G431RB（主力板）
- 江协科技 STM32 入门套件（F103C8T6，兼作 CAN 第二节点）
- CP2102 USB-TTL（3.3V）
- 830 孔面包板 + 杜邦线
