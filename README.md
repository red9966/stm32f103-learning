# stm32f103-learning

STM32F103 裸机学习实验（主线课程：**江协科技《STM32入门教程-2023版》** + 配套开发板）。
目标：第 12 周结束时做到「**我不看教程，给我一块 F103，我能从零建立工程**」。

## 硬件

| 用途 | 硬件 | 说明 |
|---|---|---|
| 学习主力 | **江协科技 STM32 入门套件** | STM32F103C8T6（Cortex-M3 @72 MHz / 64 KB Flash / 20 KB SRAM）+ 面包板 + 配套模块 |
| 串口 / 下载 | **CP2102 USB-TTL（3.3V）** | 串口调试；串口下载时配合 FlyMcu 使用 |
| 调试（可选） | ST-Link V2 | 在线断点调试；只用串口下载也能走完前 8 周 |
| 第 8 周再买 | SN65HVD230 ×2 + 120 Ω 终端电阻 | CAN 实验；板子本身没有 CAN 收发器 |
| 阶段 3 才用 | NUCLEO-G431RB | **FOC / 电机控制**主力板，12 周基础阶段用不到 |

> **为什么不直接上 G431**：F103 适合跟着课程把外设基础打牢；G431（Cortex-M4 @170 MHz、CAN FD、面向电机控制）留到阶段 3 做 FOC 时再当主力。**F103 不适合当 FOC 平台**，别在这里纠结。

## 工具链

- **主线**：Keil MDK5 + `Keil.STM32F1xx_DFP` 器件支持包 + 江协课程配套的标准外设库工程模板
- **下载方式**：① 串口下载（FlyMcu / STM32CubeProgrammer 走 UART）② ST-Link（可断点调试，强烈推荐）
- **想走 HAL 路线**：用江协官方的 **HAL 库重制版**课程，工具换 STM32CubeIDE（见 `docs/toolchain.md`）
